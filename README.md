Grocery Budget Scheduling System
📌 Project Overview

The Grocery Budget Scheduling System is a smart web-based application developed to help users plan and optimize grocery shopping within a fixed budget. The system uses Greedy Algorithm, Knapsack-based optimization, and Smart Scheduling techniques to intelligently adjust item quantities based on previous month purchase history while prioritizing essential items.

🚀 Features
User Registration & Login System
Budget-based Grocery Planning
Smart Quantity Scheduling using Previous Month Data
Essential Item Prioritization
Greedy Algorithm for Item Selection
Modified Knapsack Optimization for Budget Adjustment
Quantity Reduction Instead of Direct Item Removal
Real-time Budget Suggestions
Add New Grocery Items Dynamically
Responsive Bootstrap-based UI

🧠 Algorithms Used
1. Greedy Algorithm
Prioritizes essential grocery items first.
Helps maximize the number of items included within the budget.
2. Modified Knapsack Algorithm
Optimizes grocery selection according to budget constraints.
Instead of removing items directly, it proportionally reduces quantity.
3. Smart Scheduling
Uses last month purchase data to adjust current month quantity.
Prevents over-purchasing and reduces wastage.

⚙️ Project Workflow
User logs into the system.
User enters budget and item quantities.
System fetches previous month purchase data.
Smart Scheduling adjusts quantities.
Greedy Algorithm prioritizes essential items.
Modified Knapsack optimization adjusts quantities to fit the budget.
Final optimized shopping list is displayed.
